# Simulation de l'Algorithme RSA - Gestion des Réseaux et Sécurité

Ce dépôt GitHub présente un projet académique réalisé dans le cadre du module de **Cryptographie**, à la demande du professeur **Ayoube Jibouni** (Chef de filière *Gestion des Réseaux et Sécurité*). 

Ce travail a été développé durant le **Semestre 3 (S3)** de la **2ème année** de formation en Réseaux et Sécurité.

## 🎯 Objectif du Projet

À l'origine, il nous a été demandé de créer une représentation interactive en **React** pour simuler un système de gestion de sécurité basé sur la cryptographie asymétrique (plus précisément l'algorithme RSA). 

Cependant, comme l'apprentissage de ce module de cryptographie coïncidait avec nos tout débuts en développement web, nous avons fait le choix stratégique d'utiliser des technologies fondamentales (**HTML, CSS et JavaScript pur**) pour concevoir une simulation simple, claire et pleinement fonctionnelle, tout en respectant l'objectif pédagogique initial.

---

## 📂 Structure du Projet

Voici un aperçu de l'organisation des fichiers et dossiers du dépôt :

| Dossier / Fichier | Type | Description / Rôle |
| :--- | :--- | :--- |
| `index.html` | Page principale | Interface d'accueil et point d'entrée de la simulation. |
| `crypt.html` | Page fonctionnelle | Interface dédiée à la simulation du chiffrement et du déchiffrement RSA. |
| `about.html` | Page d'information | Présentation du projet et du contexte académique. |
| `stats.html` | Page analytique | Visualisation des données ou métriques de simulation. |
| `css/styles.css` | Feuille de style | Conception de l'interface graphique et de la mise en page. |
| `scripts/script.js` | Script JavaScript | Logique de simulation de l'algorithme RSA et interactivité de la page. |
| `imgs/` | Dossier multimédia | Contient les images et illustrations utilisées sur le site web. |

---

## 💻 Technologies Utilisées

* **HTML5** : Structure sémantique des pages web.
* **CSS3** : Mise en forme et design simple et ergonomique.
* **JavaScript (Vanilla)** : Implémentation de la logique de simulation cryptographique (RSA).

---

## 🚀 Utilisation

1. Clonez ou téléchargez ce dépôt sur votre machine.
2. Ouvrez le fichier `index.html` directement dans votre navigateur web préféré.
3. Naviguez à travers les différentes pages pour tester la simulation de la gestion de sécurité et de l'algorithme RSA.
